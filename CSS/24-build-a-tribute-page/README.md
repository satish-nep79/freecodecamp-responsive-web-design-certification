# Build a Tribute Page

This project is part of the freeCodeCamp Responsive Web Design certification.

The goal of this project was to create a tribute page for Dr. Norman Borlaug with a clear visual hierarchy, responsive image, biography timeline, and supporting links.

## Features
- Centered tribute page with a title and introductory statement
- Responsive image with descriptive alternative text and caption
- Chronological timeline of Dr. Borlaug's life and achievements
- Supporting testimonial section
- External link to a Wikipedia biography
- Semantic figure, heading, list, paragraph, and address content

## Technologies Used
- HTML5
- CSS3

## What I Learned
- How to structure a biography with semantic HTML elements
- Creating a readable timeline with an ordered visual flow
- Making images responsive with `max-width` and `height: auto`
- Building a centered layout with consistent spacing and typography
- Using descriptive link and image text to support accessibility

## Sections Included
- Tribute page heading and introduction
- Image and caption
- Timeline of Dr. Borlaug's life
- Testimonial
- Link to additional information

## CSS Concepts Practiced
- Centered content and responsive sizing
- Typography scale and font-weight hierarchy
- Background colors, padding, and rounded corners
- Responsive image sizing
- Maximum-width text blocks and readable line-height
